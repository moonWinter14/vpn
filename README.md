# 🌐 VPN Admin Panel

## 📝 Обзор
VPN Admin Panel — это полнофункциональное приложение для управления пользователями VPN. Проект включает бэкенд на Flask, базу данных MySQL и адаптивный интерфейс на Bootstrap.

## ⚙️ Функциональные возможности

### ✨ Основные функции
- 🔑 Аутентификация пользователей (регистрация, вход и выход)
- 🛠️ Административная панель для управления пользователями
- 📂 Загрузка пользователей из CSV-файла
- 🗑️ Удаление пользователей через панель администратора

### 🖥️ Панель администратора
- 👁️ Просмотр всех зарегистрированных пользователей
- ➕ Добавление пользователей через загрузку CSV
- 🗑️ Удаление пользователей

### 👤 Учетная запись пользователя
- 👀 Просмотр деталей профиля пользователя (имя пользователя и 📧 email)
- 🛡️ Административные права для различия администраторов и обычных пользователей

## 🛠️ Используемые технологии

### 🖧 Бэкенд
- 🐍 **Flask**: Веб-фреймворк

## 🚀 Инструкции по настройке

### 🧾 Предварительные требования
- 🐍 Python 3.8+
- 🛢️ База данных MySQL

### 📥 Установка
1. 📦 Клонируйте репозиторий:
   ```bash
   git clone https://github.com/your-repo/vpn-admin-panel.git
   cd vpn-admin-panel
   ```

2. ⚙️ Настройте виртуальное окружение:
   ```bash
   python3 -m venv venv
   source venv/bin/activate  # Для Windows: venv\Scripts\activate
   ```

3. 📦 Установите необходимые зависимости:
   ```bash
   pip install -r requirements.txt
   ```
    
4. 🔧 Настройте подключение к базе данных:
   Обновите словарь `DB_CONFIG` в `app.py`, указав свои учетные данные MySQL.

5. ▶️ Запустите приложение:
   ```bash
   python app.py
   ```

6. 🌐 Доступ к приложению: `http://127.0.0.1:5000/`.

### 📤 Развертывание
Для продакшена используйте сервер WSGI, например, `gunicorn`, или разверните приложение на таких платформах, как AWS, Heroku или Docker.

## 📖 Использование

### 🛠️ Действия администратора
1. 🔑 Войдите как администратор.
2. 🌐 Доступ к панели администратора: `/apanel`.
3. 📂 Загружайте CSV-файлы для добавления пользователей или 🗑️ удаляйте пользователей через таблицу.

### 👤 Действия обычных пользователей
1. 📝 Зарегистрируйтесь и войдите в систему.
2. 👀 Просмотрите данные учетной записи на странице `/account`.

### 📋 Формат загрузки CSV
CSV-файл должен содержать следующие столбцы:
- `username`
- `mail`
- `password`

### 📄 Пример CSV:
```csv
username,mail,password
user1,email1@example.com,password1
user2,email2@example.com,password2
```

## 🌐 API Endpoints

| ⚙️ Метод | 🌐 Endpoint             | 📝 Описание                   |
|----------|-------------------------|--------------------------------|
| GET      | `/`                     | 📄 Страница входа             |
| POST     | `/register`             | 📝 Регистрация пользователя   |
| POST     | `/login`                | 🔑 Вход пользователя          |
| GET      | `/logout`               | 🚪 Выход пользователя         |
| GET      | `/account`              | 👤 Страница учетной записи    |
| GET      | `/apanel`               | 🛠️ Панель администратора      |
| POST     | `/upload_csv`           | 📂 Загрузка пользователей из CSV |
| POST     | `/delete_user/<id>`     | 🗑️ Удаление пользователя по ID |
